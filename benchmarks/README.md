# Comparable wire benchmark

Run it with:

```text
cargo bench --bench compare
```

The harness uses a baseline shape (three roles, eight attachments, three metadata entries) and a heavy shape (64 roles, 256 attachments, 64 metadata entries). It reports encoded size, encode time, owned decode time, borrowed decode plus full iteration time, and allocation count for Typikon and FlatBuffers.

FlatBuffers uses the checked-in schema in `collection.fbs` and code generated by `flatc`. Its borrowed path reads the generated table and vectors directly from the input buffer; its owned path copies strings and materializes collections.

The benchmark is a local CPU/memory baseline, not a network benchmark. Run both formats on the same machine and build profile before drawing conclusions.
